# horarios_profesionales

Módulo integral de gestión de horarios, ausencias, festivos y tiempos de atención para profesionales.

## Estructura del Proyecto

- `app/`: Aplicación frontend en Next.js (App Router, Tailwind/CSS, TypeScript)
- `lib/`: Conectores y utilitarios para base de datos Oracle
- `database/`: Scripts DDL, paquetes PL/SQL (DAO, PKGCA, PKGCN, PKGLN) y documentación arquitectónica
- `types/`: Definiciones de interfaces y tipos TypeScript
